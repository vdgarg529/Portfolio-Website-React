# Part C: Measures of Central Tendency

## 6. Mean

The mean is the sum of all values divided by the number of values.

Formula:

```text
Mean = Sum of values / Number of values
```

Example:

```text
Values: 10, 20, 30

Mean = (10 + 20 + 30) / 3
     = 20
```

Using Pandas:

```python
mean_value = df["sales"].mean()
```

Using NumPy:

```python
mean_value = np.mean(
    df["sales"]
)
```

### When to use mean

Use mean when:

```text
Data is numerical
The distribution is approximately symmetric
There are no major outliers
Every value should contribute to the result
```

Examples:

```text
Average marks
Average temperature
Average production
Average response time
```

### When not to use mean

Avoid relying only on the mean when:

```text
Data is strongly skewed
Extreme outliers are present
The feature is categorical
```

Example:

```text
Salaries:
₹25,000
₹30,000
₹35,000
₹40,000
₹10,00,000
```

The mean is heavily affected by the extremely high salary.

---

## 7. Median

The median is the middle value after sorting the data.

Example with an odd number of values:

```text
10, 20, 30, 40, 50

Median = 30
```

Example with an even number of values:

```text
10, 20, 30, 40

Median = (20 + 30) / 2
       = 25
```

Using Pandas:

```python
median_value = df["income"].median()
```

Using NumPy:

```python
median_value = np.median(
    df["income"]
)
```

### When to use median

Use median when:

```text
Data is skewed
Outliers are present
You want the central position rather than the arithmetic average
```

Common examples:

```text
Income
House prices
Property values
Transaction amounts
Delivery times
```

---

## 8. Mode

The mode is the most frequently occurring value.

```python
mode_values = df["city"].mode()
```

Get the first mode:

```python
most_common_city = (
    df["city"]
      .mode()
      .iloc[0]
)
```

Frequency table:

```python
df["city"].value_counts()
```

### When to use mode

Use mode for:

```text
Categorical data
Most common product
Most common city
Most common response
Most frequent transaction type
```

The mode can also be used for discrete numerical data.

A dataset can have:

```text
One mode
Multiple modes
No mode
```

---

## 9. Mean vs Median vs Mode

```text
Mean:
Best for symmetric numerical data.

Median:
Best for skewed numerical data or data with outliers.

Mode:
Best for categorical data or most frequent values.
```

Example:

```python
summary = {
    "mean": df["salary"].mean(),
    "median": df["salary"].median(),
    "mode": df["salary"].mode().iloc[0]
}

print(summary)
```

If:

```text
Mean is much greater than median:
The data may be right-skewed.

Mean is much less than median:
The data may be left-skewed.

Mean and median are similar:
The data may be relatively symmetric.
```

# Part D: Measures of Dispersion

## 10. Range

Range is the difference between maximum and minimum values.

Formula:

```text
Range = Maximum - Minimum
```

Using Python:

```python
data_range = (
    df["sales"].max()
    - df["sales"].min()
)
```

### When to use

Use range for a quick overview of total spread.

Limitation:

```text
It depends only on the smallest and largest values.
It is highly affected by outliers.
```

---

## 11. Variance

Variance measures the average squared distance of values from the mean.

```python
variance = df["sales"].var()
```

Population variance:

```python
population_variance = df["sales"].var(
    ddof=0
)
```

Sample variance:

```python
sample_variance = df["sales"].var(
    ddof=1
)
```

### Interpretation

```text
Low variance:
Values are concentrated near the mean.

High variance:
Values are widely spread.
```

Variance is expressed in squared units, so it may be difficult to interpret directly.

---

## 12. Standard Deviation

Standard deviation is the square root of variance.

```python
standard_deviation = (
    df["sales"].std()
)
```

Population standard deviation:

```python
population_std = df["sales"].std(
    ddof=0
)
```

### Interpretation

```text
Small standard deviation:
Values are close to the mean.

Large standard deviation:
Values vary greatly.
```

### When to use

Use standard deviation when:

```text
Data is numerical
The mean is meaningful
You want variability in the original measurement units
```

Examples:

```text
Variation in test scores
Variation in delivery time
Volatility of returns
Variation in machine output
```

---

## 13. Mean and Standard Deviation Together

```python
mean_value = df["score"].mean()
std_value = df["score"].std()

print(
    f"Mean: {mean_value:.2f}"
)

print(
    f"Standard deviation: {std_value:.2f}"
)
```

For approximately normal data:

```text
About 68% of observations lie within 1 standard deviation.

About 95% lie within 2 standard deviations.

About 99.7% lie within 3 standard deviations.
```

This is called the empirical rule.

---

## 14. Interquartile Range

The interquartile range measures the spread of the middle 50% of values.

Formula:

```text
IQR = Q3 - Q1
```

Using Python:

```python
q1 = df["income"].quantile(0.25)
q3 = df["income"].quantile(0.75)

iqr = q3 - q1
```

### When to use

Use IQR when:

```text
The distribution is skewed
Outliers are present
The median is being used
```

IQR is more robust than the range and standard deviation.

---

## 15. Coefficient of Variation

The coefficient of variation measures standard deviation relative to the mean.

Formula:

```text
CV = Standard deviation / Mean
```

Using Python:

```python
coefficient_of_variation = (
    df["sales"].std()
    / df["sales"].mean()
)
```

As a percentage:

```python
cv_percent = (
    coefficient_of_variation * 100
)
```

### When to use

Use the coefficient of variation when comparing variation across variables with different units or average values.

Example:

```text
Product A:
Average sales = 100
Standard deviation = 10
CV = 10%

Product B:
Average sales = 1000
Standard deviation = 200
CV = 20%
```

Product B is more variable relative to its average.

Avoid using CV when the mean is zero or close to zero.

# Part F: Distribution Shape

## 19. Skewness

Skewness measures the asymmetry of a distribution.

```python
skewness = df["income"].skew()
```

Interpretation:

```text
Skewness near 0:
Approximately symmetric.

Positive skewness:
Long tail on the right.

Negative skewness:
Long tail on the left.
```

Rough guideline:

```text
-0.5 to 0.5:
Approximately symmetric.

0.5 to 1 or -0.5 to -1:
Moderately skewed.

Greater than 1 or less than -1:
Strongly skewed.
```

### When to use

Use skewness when deciding:

```text
Mean versus median
Whether to use a log transformation
Whether outliers may be affecting the distribution
Whether normality assumptions are reasonable
```

---

## 20. Right-Skewed Distribution

Example:

```text
Income
House price
Transaction amount
Website traffic
```

Typical relationship:

```text
Mean > Median > Mode
```

A few large values pull the mean upward.

---

## 21. Left-Skewed Distribution

Example:

```text
Scores on an easy examination
Customer ratings where most ratings are high
```

Typical relationship:

```text
Mean < Median < Mode
```

A few low values pull the mean downward.

---

## 22. Kurtosis

Kurtosis measures the heaviness of the distribution tails.

```python
kurtosis = df["returns"].kurt()
```

Pandas returns excess kurtosis:

```text
Around 0:
Similar to a normal distribution.

Greater than 0:
Heavier tails and potentially more extreme values.

Less than 0:
Lighter tails and fewer extreme values.
```

### When to use

Use kurtosis in:

```text
Financial returns
Risk analysis
Anomaly analysis
Quality-control measurements
```

# Part K: Relationship Analysis

## 40. Covariance

Covariance measures whether two numerical variables change together.

```python
covariance = df[
    ["sales", "profit"]
].cov()
```

Interpretation:

```text
Positive covariance:
Variables tend to increase together.

Negative covariance:
One tends to increase while the other decreases.

Near-zero covariance:
Little linear co-movement.
```

Limitation:

```text
Covariance depends on variable units.
Its magnitude is difficult to compare across datasets.
```

---

## 41. Correlation


Correlation values usually range between:

```text

```

Interpretation:

```text

Perfect positive relationship.

0:
No linear relationship.

-1:
Perfect negative relationship.
```

## 47. Important Correlation Warning

Correlation does not prove causation.

Example:

```text
Ice cream sales and drowning incidents may both increase in summer.
```

This does not mean ice cream causes drowning.

Both are influenced by another variable:

```text
Temperature
```

Always consider:

```text
Confounding variables
Reverse causality
Coincidental relationships
Data leakage
```

## 74. Effect Size

Cohen's d measures the standardized difference between two means.

```python
pooled_std = np.sqrt(
    (
        group_a.var(ddof=1)
        + group_b.var(ddof=1)
    )
    / 2
)

cohens_d = (
    group_a.mean()
    - group_b.mean()
) / pooled_std
```

Rough interpretation:

```text
0.2:
Small effect.

0.5:
Medium effect.

0.8:
Large effect.
```

These are rough guidelines and depend on the domain.

# Part S: Statistical Testing Introduction

## 75. Null and Alternative Hypotheses

Example question:

```text
Does the new marketing campaign increase sales?
```

Null hypothesis:

```text
H₀:
The campaign does not change average sales.
```

Alternative hypothesis:

```text
H₁:
The campaign changes or increases average sales.
```

---

## 76. P-Value

The p-value measures how compatible the observed result is with the null hypothesis.

Common decision rule:

```text
If p-value < 0.05:
Reject the null hypothesis.

If p-value ≥ 0.05:
Do not reject the null hypothesis.
```

Important:

```text
A p-value is not the probability that the null hypothesis is true.
```

Statistical significance does not automatically mean practical importance.

---

## 77. Independent Two-Sample T-Test

```python
from scipy.stats import ttest_ind

statistic, p_value = ttest_ind(
    group_a,
    group_b,
    equal_var=False,
    nan_policy="omit"
)

print(statistic)
print(p_value)
```

### When to use

Use an independent t-test when:

```text
Comparing means of two independent groups
The outcome is numerical
Observations are independent
```

Welch's t-test with:

```python
equal_var=False
```

is generally safer when group variances or sizes differ.

---

## 81. One-Way ANOVA

```python

    df["region"] == "North",

    "sales"
```

---

## 82. Test Selection Guide

```text
Two independent numerical groups:
Independent t-test or Mann-Whitney U.

Two paired numerical measurements:
Paired t-test or Wilcoxon signed-rank.

Three or more numerical groups:
ANOVA or Kruskal-Wallis.

Two categorical variables:
Chi-square test.

Relationship between two numerical variables:
Correlation or regression.
```

## 87. Numerical Analysis Template

```python
def analyze_numeric_column(
    df,
    column
):
    series = df[column].dropna()

    summary = {
        "count": series.count(),
        "mean": series.mean(),
        "median": series.median(),
        "mode": (
            series.mode().iloc[0]
            if not series.mode().empty
            else np.nan
        ),
        "minimum": series.min(),
        "maximum": series.max(),
        "range": (
            series.max()
            - series.min()
        ),
        "variance": series.var(),
        "standard_deviation": series.std(),
        "q1": series.quantile(0.25),
        "q3": series.quantile(0.75),
        "iqr": (
            series.quantile(0.75)
            - series.quantile(0.25)
        ),
        "skewness": series.skew(),
        "kurtosis": series.kurt()
    }

    return pd.Series(summary)
```

```python
    "sales"
)
```

# Part Y: Common Analysis Mistakes

## 96. Reporting Only the Mean

A mean without spread may be misleading.

Better:

```python
summary = df["sales"].agg([
    "mean",
    "median",
    "std",
    "min",
    "max"
])
```

Report:

```text
Average
Median
Variation
Sample size
Range or percentiles
```

---

## 97. Ignoring Sample Size

An average based on five observations is not as reliable as an average based on five thousand observations.

Always include:

```python
df.groupby("region").agg(
    average_sales=(
        "sales",
        "mean"
    ),
    sample_size=(
        "sales",
        "count"
    )
)
```

---

## 98. Confusing Correlation with Causation

A strong correlation may be caused by:

```text
A third variable
Reverse causality
Coincidence
Selection bias
Time trends
```

---

## 99. Comparing Groups Without Checking Distribution

Two groups may have similar means but very different spreads.

Check:

```text
Mean
Median
Standard deviation
Sample size
Box plot
Distribution
```

---

## 100. Ignoring Missing Values

A calculated mean may use fewer observations than expected.

Check:

```python
df["sales"].count()
df["sales"].isna().sum()
```

---

## 101. Ignoring Multiple Comparisons

When testing many hypotheses, some may appear significant by chance.

Use corrections such as:

```text
Bonferroni correction
False discovery rate
```

when many statistical tests are performed.

---

## 102. Using Statistical Significance Alone

A very small difference can become statistically significant in a very large dataset.

Always evaluate:

```text
P-value
Effect size
Confidence interval
Business importance
```
