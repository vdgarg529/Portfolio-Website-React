# Introduction

Every process in Linux has limits like:

- How many files it can open
- How much memory it can use
- How many processes it can spawn

`ulimit` lets you:

- **View** those limits
- **Set** them (temporarily or permanently)


# Types

There are **two kinds of limits**:

### 1. Soft limit

- Current enforced limit
- Can be changed by the user (within bounds)

### 2. Hard limit

- Maximum allowed value for soft limit
- Only root can increase it


# Check current limits

```bash
# show all limits
ulimit -a
```


Typical output includes:
- open files (`-n`)
- max user processes (`-u`)
- stack size (`-s`)
- core file size (`-c`)
- virtual memory (`-v`)

# Common options (important ones)

|Option|Meaning|
|---|---|
|`-n`|Max number of open file descriptors|
|`-u`|Max number of user processes|
|`-f`|Max file size|
|`-s`|Stack size|
|`-v`|Virtual memory|
|`-c`|Core dump size|
|`-t`|CPU time limit|
|`-l`|Locked memory|

# Setting limits

### Example: Increase open files

```bash
ulimit -n 4096
```

### Set unlimited

```bash
ulimit -c unlimited
```


### Set soft vs hard explicitly

```bash
ulimit -Sn 4096   # soft
ulimit -Hn 8192   # hard
```


# Important behavior

### 1. It’s per-shell session

- Changes apply only to the current terminal
- Open a new terminal → reset

### 2. Child processes inherit limits

If you run a program after setting `ulimit`, it inherits those limits.

### 3. Cannot exceed hard limit (as normal user)

```bash
ulimit -n 100000  # ❌ fails if hard limit is lower
```
