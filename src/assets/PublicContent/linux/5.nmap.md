- ### **Nmap** is a command-line utility that sends specially crafted network packets to systems and then analyzes the responses.

- ### **Nmap (Network Mapper)** is an open-source tool used for:

	- **Network discovery**
	- **Port scanning**
	- **Service & OS identification**
	- **Security auditing**
- ### Nmap operates by interacting with the **TCP/IP stack** of a target:

	1. Sends packets (SYN, ACK, UDP, ICMP, etc.)
	2. Observes responses (or lack of response)
	3. Uses patterns to determine:
	    - Is host alive?
	    - Which ports are open?
	    - What service is running?
	    - What OS is likely used?


# 1. Host Discovery (Who is alive?)

Before scanning ports, Nmap checks if a host is up.

### Methods:

- ICMP echo (ping)
- TCP SYN to common ports
- ARP (local network)

```bash
nmap -sn 192.168.1.0/24
```

with MAC-ADDR

```bash
sudo nmap -sn 192.168.1.0/24
```


# 2. Port Scanning (Core Feature)

Ports are classified as:

| State        | Meaning                   |
| ------------ | ------------------------- |
| **open**     | Service is listening      |
| **closed**   | No service, but reachable |
| **filtered** | Blocked by firewall       |

## Common Scan Types

### 1. TCP SYN Scan (Stealth)

```bash
sudo nmap -sS target
```
- Sends SYN, doesn’t complete handshake
- Fast and widely used

---

### 2. TCP Connect Scan

```bash
nmap -sT target
```

- Full handshake
- Slower, no root needed

---

### 3. UDP Scan

```bash
sudo nmap -sU target
```

- Finds UDP services (DNS, DHCP)
- Slow and less reliable

---

### 4. ACK Scan (Firewall detection)

```bash
nmap -sA target
```

---

### 5. FIN / NULL / XMAS (Stealthy variants)

```bash
nmap -sF target
nmap -sN target
nmap -sX target
```



# Service & Version Detection

```bash
nmap -sV target
```

Nmap:

- Connects to open ports
- Sends probes
- Matches responses with its database

👉 Example output:

```bash
80/tcp open  http  Apache httpd 2.4.41
```

---

# 💻 4. OS Detection

```bash
sudo nmap -O target
```


Uses:

- TCP/IP fingerprinting
- TTL values
- Window sizes
- Packet behavior

👉 Output:

```bash
OS: Linux 5.x
```

---

# 5. Aggressive Scan

```bash
sudo nmap -A target
```

Includes:

- OS detection
- Version detection
- Script scanning
- Traceroute

👉 Quick but noisy (easily detected)



# 6. Nmap Scripting Engine (NSE)

One of the most powerful features.

### Categories:

- `auth` – authentication checks
- `vuln` – vulnerability detection
- `safe` – safe scripts
- `exploit` – exploitation attempts

---

### Example:

```bash
nmap --script=vuln target
```

### Specific script:

```bsah
nmap --script=http-title target
```

👉 Can:

- Detect CVEs
- Check weak configs
- Grab banners


# 7. Performance & Timing

Timing templates:

```bash
-T0 → paranoid (very slow)
-T3 → default
-T4 → fast
-T5 → very aggressive
```

Example:

```bash
nmap -T4 target
```


# 8. Target Specification

You can scan:

### Single host

```bash
nmap 192.168.1.1
```

### Range

```bash
nmap 192.168.1.1-50
```

### Subnet

```bash
nmap 192.168.1.0/24
```

### From file

```bash
nmap -iL targets.txt
```

# 🧠 10. Interpreting Results (VERY IMPORTANT)

Example:

```bash
PORT   STATE  SERVICE  
22/tcp open   ssh  
80/tcp open   http  
443/tcp closed https
```
### Meaning:

- SSH & HTTP are accessible
- HTTPS is not running

👉 Combine with `-sV`:

```bash
80/tcp open http Apache 2.4.49
```

Now you know:

- Exact service
- Version → potential vulnerability

# 🔐 11. Real-World Use Cases

## 🛡️ Security Auditing

- Find open ports
- Detect outdated software
- Identify attack surface

---

## 🧑‍💻 Ethical Hacking / Pentesting

Typical workflow:

1. Discover hosts (`-sn`)
2. Scan ports (`-sS`)
3. Detect services (`-sV`)
4. Run scripts (`--script=vuln`)

---

## 🖧 Network Management

- Inventory devices
- Monitor services
- Check firewall rules

---

## 🧪 Debugging

- Why is port blocked?
- Is service running?
- Network path issues

---

# ⚠️ 12. Limitations

- Firewalls can hide ports
- IDS/IPS may block scans
- OS detection is probabilistic
- UDP scans are slow/unreliable

---

# 🚨 13. Legal & Ethical Considerations

- Scanning without permission can be **illegal**
- Always use on:
    - Your own systems
    - Labs (e.g., VM networks)
    - Authorized environments

---

# 🧰 14. Pro Tips

### Scan all ports + detect services:

```bash
sudo nmap -p- -sV target
```

### Fast reconnaissance:

```bash
nmap -T4 -F target
```

### Stealthy scan:

```bash
sudo nmap -sS -T2 target
```

### Find only open ports:

```bash
nmap --open target
```
